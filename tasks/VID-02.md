# タスク: VID-02 場面分割とフレーム抽出（ffmpeg）

## 目的
映像を場面（時間区間）に分け、各場面の代表フレームとサムネイルを作る。**時刻は必ずここで確定させ、
以降 LLM に時刻を答えさせない。**

## 仕様参照: specs/20-video-search.md §3（1〜2）/ ADR-0032 決定2・決定3

## 前提
- VID-01（映像が Object Storage にある）

## 作業内容
- 依存に `imageio-ffmpeg` を追加（**pip。apt は使わない** — Containerfile のレイヤ設計を崩さないため）
- `jetuse_core/video_frames.py`
  - 場面転換検出（`select='gt(scene,X)'`）で一次分割
  - 短すぎる区間は併合、長すぎる区間は分割（上限・下限は定数で持ち、根拠をコメントに書く）
  - 各区間から代表フレームを数枚（視覚 LLM へ渡す用）
  - 場面サムネイル JPEG を Object Storage へ
- 尺・解像度・fps の取得（`VIDEO_ASSETS.duration_ms`）

## 完了条件
- 実際の映像ファイルで、場面数と境界が妥当であること（レポートに映像・境界・サムネイルを載せる）
- **転換が無い映像**（1カット）でも1場面として成立すること
- **壊れた映像・音声のみのファイル**を渡したときに握りつぶさず理由付きで失敗すること
- 単体テスト: 併合・分割の境界条件、ffmpeg が無い/失敗したときの扱い

- ffmpeg の失敗を握りつぶして「場面0件」で正常終了すること
