# タスク: PREP-01 xlsx の前処理（セル位置つき抽出）と取り込み口

## 目的
**Excel（xlsx）を JetUse API に投げると、シート名とセル範囲を持ったチャンクとして
取り込める**ようにする。これが揃うと「仕様書 v2.0 の『制約』シート C5:E5 が根拠」まで
返せるようになり、案件デモを JetUse API だけで組む道が通る。

ADR-0020 の決定（選べる 2 バックエンド）と RAGM-01 / RAGM-02 で、
**メタデータの配管は既に完成している**（`rag_metadata.ATTRIBUTE_KEYS` に
`file` / `version` / `sheet` / `cells` / `sha256` / `kind` / `current_version` / `chunk_id`）。
本タスクで足りていないのは**入口**だけ: `rag.ALLOWED_EXTENSIONS` が `.pdf` / `.txt` / `.md` のみ。

api

## 前提（依存タスク / 人間の事前作業）
- RAGM-01 / RAGM-02 がマージ済み（済）。
- 検証は**架空の xlsx**で行う。顧客の実ファイルは使わない。

## 設計上いちばん重要な制約（実測済み・作り直さないこと）
マネージド Vector Store の属性は **ファイル単位**で、1 ファイルが複数チャンクに割れても
**属性は 1 種類しか持てない**（SPIKE-M1 ①-a で実測）。したがって:

| バックエンド | xlsx の出典粒度 |
|---|---|
| `vector_store`（マネージド） | **ファイル単位**。`sheet` / `cells` は「そのファイル全体の範囲」を表す値になる |
| `adb`（Oracle AI Database） | **チャンク単位**。シート・セル範囲がチャンクごとに異なる |

**この差を隠さないこと。** 「マネージドでもセル単位で返る」ように見せる実装（1 チャンク＝1 ファイルで
無理に分割する等）はしない。差があることが ADR-0020 の決定内容そのものであり、
その可視化は RAGM-03 の担当。

## 作業内容
### 1. 抽出（層1）
- 新規モジュール（例 `jetuse_core/extract_xlsx.py`）。**openpyxl は read_only + data_only** で開く
  （大きなブックでメモリを食わない・数式でなく値を取る）。
- シートごとに走査し、**連続する非空セルの矩形**を 1 チャンクにまとめる。
  各チャンクに `sheet`（シート名）と `cells`（A1 形式の範囲。例 `B12:F48`）を持たせる。
- テキスト化は**行単位でセルをタブ区切り**にする程度でよい（凝った表整形はしない）。
- 上限を設ける（総チャンク数・1 チャンクの文字数・ブック全体のバイト数）。
  超過は**切り詰めるのではなく 422 で拒否**し、何が上限に当たったかを detail に書く。
- 空シート・結合セル・数式セル・巨大な空白領域で落ちないこと。

### 2. 取り込み口（層2）
- `rag.ALLOWED_EXTENSIONS` に `.xlsx` を追加し、取り込み時に上記の抽出を通す。
- `adb` バックエンドでは**抽出したチャンクをそのまま**投入する（`sheet` / `cells` が
  チャンクごとに異なる状態）。
- `vector_store` バックエンドではファイル単位の属性として投入する（上記の制約どおり）。

### 3. 抽出だけ使う口（層1 の公開）
- `POST /api/extract` を追加。ファイルを渡すと**抽出結果（チャンクとメタデータ）を返すだけ**で、
  取り込みはしない。案件側が独自の構造化を挟みたいときの口。
- 認証・サイズ上限は既存のアップロード経路に合わせる。

## 非ゴール / 禁止事項
- **docx / pptx / 画像 / スキャン PDF の OCR 結線はしない**（優先順の 2〜4。別タスク）。
- マネージド側で「チャンク単位に見せる」細工をしない。**能力差を隠さない**。
- 能力差の UI 表示はしない（RAGM-03 の担当）。
- 凝った表構造の復元（結合セルの意味解釈・ヘッダ推定）はしない。まず位置が取れることを優先。
- 顧客データを持ち込まない（架空の xlsx のみ）。**顧客名・案件名を書かない**（公開リポジトリ）。
- 認証情報・OCID をコミットしない。IAM を変更しない。
- 未承認のコミット / PR / push を行わない（人間ゲート）。
