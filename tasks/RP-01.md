# タスク: RP-01 開発環境の DB 内資格情報をリソースプリンシパルへ統一する

## 目的
開発環境の `DBMS_CLOUD` / `DBMS_CLOUD_AI` が使う資格情報を、開発者の API キー由来
（`JETUSE_OCI_CRED`）から **`OCI$RESOURCE_PRINCIPAL`** へ統一する。
`ops/` が `~/.oci/config` を読んで DB へ API キーを焼き込む経路そのものを廃止する。

決定と背景は `docs/decisions/ADR-0021-dev-resource-principal.md`。
ADR は 2026-07-29 に承認済み（Accepted）。

## 仕様参照
- `docs/decisions/ADR-0021-dev-resource-principal.md`（本タスクの正本）
- `CLAUDE.md`「環境・認証の扱い」: OCI ログイン方式は 1 スイッチ（`jetuse_core.oci_auth`）を必ず経由する
- `specs/09-rag.md`: ADMIN セットアップの記述（API キー credential 作成 → 本タスクで置換）

## 前提（依存タスク / 人間の事前作業）
- **ADR-0021 の承認**: 2026-07-29 に承認済み（状態 Accepted）。着手可。
- 実 ADB が起動していること（`ops/start-adb-if-stopped.sh`）。ADMIN パスワードは `.env` の
  `ADB_ADMIN_PASSWORD`（2026-07-29 にリセット済み）。
- IAM は**変更不要**（ADR-0021「実機で確認した事実」参照。動的グループもポリシーも整備済み）。
  もし検証中に権限不足が出た場合は、**IAM を自分で変更せず** blocked にして報告する。

## 作業内容
- `ops/setup-select-ai.py` / `ops/setup-dev-schema.py`:
  - `~/.oci/config` の手書きパース（計4箇所）と `DBMS_CLOUD.CREATE_CREDENTIAL` 呼び出しを**削除**。
  - 代わりに `DBMS_CLOUD_ADMIN.ENABLE_RESOURCE_PRINCIPAL(username => <schema>)` を実行する。
  - 冪等にする（既に有効なスキーマへ再実行しても失敗しない）。
- `infra/terraform/environments/app`: コンテナへ `SELECT_AI_CREDENTIAL=OCI$RESOURCE_PRINCIPAL` を注入。
- `.env.example`: `SELECT_AI_CREDENTIAL` の項を追加し、開発既定を明記。
- `settings.select_ai_credential` の既定値の扱いは **ADR §未解決 1** の判断に従う
  （実装時に決めきれない場合は現状維持＋env 注入とし、判断を ADR へ追記して人間に確認する）。
- `spikes/spike_m1/common.py:oci_api_key()` は**スパイクの再現性のため残す**が、
  「ops はこの方式を使わなくなった」旨のコメントを付ける。
- ドキュメント更新: `specs/09-rag.md` の ADMIN セットアップ記述、`docs/guides/onboarding.md` /
  `docs/guides/dev-environments.md` の手順、`docs/tips.md` の該当 Tips を「解消済み」へ。

## 非ゴール / 禁止事項
- **IAM / 動的グループ / ポリシーを変更しない**。不足が判明したら blocked にして報告する（人間ゲート）。
- 顧客環境（ワンクリック配備）側の認証経路を変更しない。もともとリソースプリンシパル。
- `AUTH_MODE` の解決ロジック（ローカル Python プロセス側の認証）を作り替えない。
- Vault 化はしない（ADR-0021 で却下。Phase 8 の検討事項）。
- 実 ADB の既存スキーマ・共有リソースを壊さない。検証用に作るものは `jetuse-spike-` 接頭辞。
- 認証情報・OCID・エンドポイント実値をコミットしない。
- **顧客名・案件名を書かない**（公開リポジトリのため）。
- 未承認のコミット / PR / push を行わない（人間ゲート）。ADR-0021 の決定内容を書き換えない
  （「未解決」への結論追記は可。決定そのものの変更は人間ゲート）。
