# タスク: VID-04 場面の横断検索（自然言語・条件・類似・根拠）

## 目的
複数映像を横断して目的の**場面**を探せるようにする。返すのは映像ではなく場面。

## 仕様参照: specs/20-video-search.md §4 / ADR-0032 決定4

## 前提
- VID-03（場面に説明とベクトルがある）

## 作業内容
- `jetuse_core/video_search.py`
  - `q` を埋め込み、**ベクトル距離とメタデータ条件を同一の SQL** で評価する
  - `q` 無し＝条件だけの絞り込み（要求5 の「一覧から条件を選択して探せる」）
  - `similar_to_scene_id`＝その場面のベクトルで再検索（要求10）
  - **根拠**（要求11）: 一致したタグ・効いた項目・距離を返し、人が読める理由文を作る
- `POST /api/video/search`
- 条件: 撮影日 / 登録日 / 所属 / カテゴリ / 場所 / 屋内外 / 昼夜 / 人物有無 / タグ / 尺 /
  分析状態 / 確認済み / 権利範囲

## 完了条件
- 「豪雨」で検索して「強い雨」「傘を差した人物」「濡れた路面」の場面が候補に出ること（実測で示す）
- 条件だけの絞り込みが動くこと
- 類似検索が動くこと
- **根拠が必ず返ること**（空の理由文を返さない）
- 単体テスト: 条件の組み合わせ、SQL インジェクション、0 件、ベクトルが無い場面の扱い

## 成果物
コード / `docs/verification/VID-01.md` に追記

## 禁止事項
- 検索結果を映像単位に丸めること（場面が主役）
- 根拠を省くこと
