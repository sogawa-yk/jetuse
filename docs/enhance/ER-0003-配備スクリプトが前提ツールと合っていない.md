## ひとことで

手順どおりに実行しても動かず、手作業での配備を強いられる。

## 何が起きるか

`ops/dev-env-up.sh` がコンテナのビルドに `podman` を直接呼ぶ。
podman が入っていない環境では**そこで止まる**。

## 根拠

2026-08-03 のシカゴ配備で踏んだ。この環境には podman が無く
（Rancher Desktop の docker / nerdctl はある）、**ビルドから配備まで手作業**で実施した。
なお `CLAUDE.md` は「podman 5.6」と記録しているが**実態と違う**。

## どう直すか

使えるものを検出して使う（podman / docker / nerdctl）。無ければ**分かる形で止める**。
あわせて `CLAUDE.md` のツール記録を実態に合わせる。

## やらない場合の代償

環境が少し違うだけで**自動化が効かない**。手順書があっても手作業に落ちる。
