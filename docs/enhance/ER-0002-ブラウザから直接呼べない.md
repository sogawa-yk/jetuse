## ひとことで

画面を作るだけのつもりが、中継サーバーを書く羽目になる。

## 何が起きるか

CORS が有効になっていない（`OPTIONS` が 405）。ブラウザで動く画面から
JetUse API を**直接呼べない**。

## 根拠

2026-08-04 に案件デモの画面を作った際、**ローカルで配信して中継する仕組みを自作**した
（`serve.py` 相当・約80行）。実測で `OPTIONS /api/chat/stream` → **405**。

## どう直すか

許可する送信元を**設定で指定できる**ようにする（全開放にはしない）。
`AUTH_REQUIRED` と組み合わせ、**無認証かつ全開放**にならないようにする。

## やらない場合の代償

デモを作る人が毎回**中継を自作**する。「画面だけ作りたい」人にとっては入口の壁になる。
