## ひとことで

いまは OCI のサービスに任せている記憶を、データベース側で持つ案。

## 何を検討したか

Oracle AI Database の Agent Memory を使う案。2026-08-01 に検討し、**保留**とした。

## 根拠

実体は Python ライブラリで、依存が約 150MB 増える。
現状は OCI 側の機能で足りており、**移す利点が依存の増加に見合わない**と判断した。

## 再開する条件

- 会話の記憶に対して**業務データと結合した検索**が必要になったとき
- 記憶の**保持期間や削除**を業務要件として制御する必要が出たとき

## やらない場合の代償

いまのところ無い。**条件が満たされたら再開する**という位置づけ。
