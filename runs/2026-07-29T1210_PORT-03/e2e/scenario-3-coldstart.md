# シナリオ3: コールドスタート実測（min_replica=0）

| 状態 | openai_agents | langgraph | adk |
|---|---:|---:|---:|
| 配備直後（ウォーム） | 1.8 s | 2.3 s | 2.3 s |
| **35分アイドル後（初回）** | **5.5 s** | **5.5 s** | **6.4 s** |

- 計測は `/api/chat/stream` へエージェント実行を投げ、SSE が `[DONE]` で閉じるまでの実時間。
  ツール実行（`get_current_time`）と LLM 応答の生成時間を含む。
- アイドル後の増分は 3〜4 秒。`jetuse_core/hosted_agent.py` の httpx timeout は 180 秒なので
  **timeout の延長は不要**と判断した。UI にコールドスタートの断り書きを出す必要も無い
  （体感で待たされる水準ではない）。
- 注意: レプリカが実際に 0 まで縮退したかを直接観測する API は見つからなかった。
  ここで示すのは「35分アイドル後の初回実行」の実測値であり、増分がその起動コストにあたる。
