# シナリオ16: 権限境界（Codex review-1 の blocker への対応）

## 見つけた実態

public-dev のポリシーを絞るだけでは閉じなかった。テナンシ直下の `jetuse-dev` ポリシーが
`jetuse-internal-dg` に **4コンパートメントへの manage all-resources** を与えており、
その DG の matching rule は **5面すべて**を拾っていた。つまりどの環境の Container Instance /
Function / ADB からでも、他環境を全操作できる状態だった。ER-0016 が指していたのもこの一部。
